# Inter 4.1

Self-hosted upright variable font downloaded from the typeface author's official distribution:
https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1

Source and usage: https://rsms.me/inter/
License: LICENSE-Inter.txt (SIL Open Font License 1.1), from https://raw.githubusercontent.com/rsms/inter/master/LICENSE.txt

No remote font request is made when viewing Selenoa. Inter is a visual reconstruction choice; the raster mockup does not provide an exact font specification.
